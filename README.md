# kayá — Cosmética Amazónica 100 % Natural y Circular

Landing page oficial para la línea de productos cosméticos **kayá**, formulados a partir del aprovechamiento integral del fruto y la nuez de **Cacay** (*Caryodendron orinocense*).

## Estructura de la Página
1. **Hero (Primera interfaz):** Paisaje amazónico (`assets/images/hero-amazonia.jpg`), marca **kayá** y eslogan.
2. **¿Qué es el Cacay?:** Explicación botánica y de cosmética circular acompañada de la imagen del fruto y las nueces de Cacay (`assets/images/cacay-fruto.jpg`).
3. **Nuestros Productos:**
   - **Cacay Amazon Origin Sérum** (`assets/images/serum.jpg`)
   - **Cacay Active Shampoo** (`assets/images/shampoo.jpg`)
   - **Cacay Nut Exfoliant** (`assets/images/exfoliant.jpg`)
   - Cada tarjeta muestra su descripción principal y cuenta con un botón interactivo (**"Visualizar qué más tiene"**) que despliega envase, modo de aplicación y beneficios con respaldo bibliográfico, además de una vista en ventana modal ampliada.
4. **Cierre / Colección Completa:** Fotografía grupal de los 3 productos (`assets/images/coleccion-kaya.jpg`) y resumen del ritual **kayá**.

## Cómo ver la página
Abre directamente el archivo `index.html` en cualquier navegador web.
